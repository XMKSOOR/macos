# تطبيق الجوال (Android) + مزامنة Supabase Postgres

هذا الدليل يشرح تشغيل «المرافق السحابي»: تطبيق أندرويد يقرأ ويضيف بيانات العيادة من/إلى
قاعدة بيانات **Supabase Postgres**، ويُغذّيها تطبيق السطح المكتب.

```
[سطح المكتب (Electron)]  --(رفع كامل)-->  [Supabase Postgres]  <--(REST)-->  [تطبيق Android]
```

## 1) تهيئة Supabase (مرة واحدة)

1. افتح مشروعك في [supabase.com](https://supabase.com) ← **SQL Editor** ← **New query**.
2. الصق كامل محتوى الملف [`schema.sql`](./schema.sql) ونفّذه. يُنشئ كل الجداول + الأمان (RLS) + دالة `reset_sequences`.
3. أنشئ مستخدماً للتطبيق: **Authentication ← Users ← Add user ← Create new user**
   - أدخل بريداً وكلمة مرور، وفعّل «Auto Confirm User».
   - هذا الحساب هو ما ستسجّل به الدخول من التطبيق.
4. من **Project Settings ← API** انسخ:
   - **Project URL** (مثل `https://xxxx.supabase.co`)
   - **anon / publishable key** (للتطبيق)
   - **service_role / secret key** (للسطح المكتب فقط — لا تضعه في التطبيق أبداً)

> ملاحظة أمنية: مفتاح `service_role` يتجاوز RLS وقوي جداً — يبقى على جهاز السطح المكتب فقط.

## 2) رفع البيانات من السطح المكتب

1. افتح تطبيق السطح المكتب ← **الإعدادات**.
2. في لوحة «قاعدة البيانات السحابية (Supabase Storage)» أدخل **Project URL** و**المفتاح السري (service_role)**.
3. في لوحة «تطبيق الجوال (Supabase Postgres)» فعّل «مزامنة تلقائية» (اختياري)، ثم اضغط:
   - **📡 اختبار اتصال Postgres** للتأكد.
   - **⬆ رفع البيانات إلى Postgres** لرفع نسخة كاملة من بيانات العيادة.
4. عند التفعيل التلقائي: تُرفع البيانات عند إغلاق البرنامج وتُسحب عند الفتح إن كانت القاعدة فارغة.

## 3) بناء وتثبيت تطبيق Android

### أ) عبر GitHub Actions (الأسهل)
- عند أي دفع يمسّ مجلد `android/`، يبني الـworkflow (`.github/workflows/android.yml`) ملف APK.
- من صفحة **Actions** اختر آخر تشغيل ← **Artifacts** ← حمّل `clinic-companion-apk`.
- انقل ملف APK إلى الهاتف وثبّته (فعّل «تثبيت من مصادر غير معروفة»).

### ب) محلياً (Android Studio أو سطر الأوامر)
```bash
cd android
gradle assembleDebug
# الناتج: app/build/outputs/apk/debug/app-debug.apk
```
يتطلب JDK 17 و Android SDK (compileSdk 34).

## 4) استخدام التطبيق

1. عند أول تشغيل: أدخل **Project URL** و**anon key** ← «حفظ ومتابعة».
2. سجّل الدخول بالبريد وكلمة المرور اللذين أنشأتهما في Supabase.
3. تبويبات التطبيق: **الرئيسية** (ملخص)، **المرضى** (بحث + ملف طبي/أدوية/مواعيد/فواتير + إضافة مريض)،
   **المواعيد** (قادمة/الكل + إضافة موعد)، **الفواتير**، **الإعدادات** (اختبار الاتصال + خروج).

## ملاحظات

- المبالغ تُعرض بافتراض مقياس العملة الافتراضي (÷100)؛ يظهر «ل.س».
- «الرفع/السحب» يستبدل الجدول كاملاً (نسخة معكوسة). تجنّب إدخال بيانات على الجوال والسطح المكتب في آن واحد قبل المزامنة.
- حقول التاريخ في Postgres نصية بصيغة `YYYY-MM-DD` (لتطابق السطح المكتب).
